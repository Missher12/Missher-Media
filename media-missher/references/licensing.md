# Licensing Boundary

The installable `media-missher` directory contains a newly authored standard-library adapter, synthetic tests are kept outside the installed directory, and no external crawler source, virtual environment, generated data, JavaScript, font, image, or inherited source header is distributed.

The external runtime remains a separate local dependency governed by the license files and restrictions supplied with that runtime, including any non-commercial-use restriction. Installing this adapter does not remove, replace, or relicense those terms.

No repository-wide license has been selected for this adapter. Do not add one, publish a combined bundle, or copy code from the external runtime until the owner chooses a license and a separate provenance review confirms every included component is distributable under compatible terms.

The rollback boundary is the adapter itself: disable or remove only the Codex skill. Never delete or rewrite the external runtime as part of rollback.
