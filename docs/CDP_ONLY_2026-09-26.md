# Chrome CDP 单一入口与代码精简

日期：2026-09-26。用户在 V17 研究后决定先只保留 Chrome CDP 并精简代码。本轮按此范围实施；此前 Computer Use 建设计划取消，其他升级与宿主修复建议暂不展开。

## 实现结果

- Python wrapper、runtime、通用 CLI 与 DSH 仅接受 `cdp`。省略时仍默认 CDP，兼容显式 `--backend cdp`。旧 Computer Use 请求、配置与计划返回 `backend-retired-computer-use`，不会自动改变用户原来的请求。
- 删除 Computer Use 生命周期命令、DSH 工具注册、控制器、宿主证据桥和 Python 执行模块。DSH 只注册 setup、collect、runs 三个工具；通用能力查询只列 Chrome CDP。
- 移除双后端能力表中的 CU 项与未使用的后端包装类。保留 CDP 的响应证据和页面证据两种数据来源，页面数据不会被伪装成响应数据。
- 保留现有平台、顺序多目标、批次恢复、截图、共享风险保护、私有历史与选择导出。
- 旧 `computer_use` 与 `browserskill` 结果仍按原来源读取和导出，但不能恢复为新采集任务。只读检查旧运行时的活动租约，防止新 CDP 任务与旧任务争抢；不再保留 CU 持有者执行入口。
- 同步 Skill、命令参考、宿主说明与项目入口，调整归档允许的文件清单，并重新构建本地 CLI/Bundle 入口和 payload。

主要代码位置为 `runtime/media_missher_runtime/`、`media-missher/scripts/run_collection.py`、`agent-plugin/bin/`、`agent-plugin/src/` 与 `harness-plugin/src/`。仅用于 CU 的 `shared/` 已移除。相对修改前快照，上述运行代码净减少 673 行，不计测试、文档、构建脚本、生成文件与归档。公开帮助也不再展示退役的浏览器辅助选项。
