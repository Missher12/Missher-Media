# Agent 接入

[返回首页](../README.md)

Media CDP 是本地 Python 程序。Agent 可通过宿主的进程工具调用，无需把模型接入采集核心。这里说明通用契约，不声明某个宿主已安装、发现或验收通过。

## 调用流程

1. 由用户确定平台、作者或关键词、条数、允许的导航和输出位置。
2. 检查 Python 环境与本机 Chrome 端点，登录由用户手动处理。
3. 使用参数数组启动进程，设置有限超时与取消逻辑，避免字符串拼接进入 shell。
4. 收集退出码、标准错误和输出目录中的运行清单。
5. 报告实际条数、状态、缺失字段和停止原因；导出另行调用本地接口。

例如，宿主在 Python 中构造参数：

```python
argv = [
    python_executable,
    "runtime/scripts/scrape_all.py",
    "creator", "--platforms", "bilibili",
    "--bilibili-uid", confirmed_creator_id,
    "--count", "1",
    "--cdp-url", "http://127.0.0.1:9222",
    "--allow-navigation",
    "--output-dir", output_directory,
]
```

变量由调用方提供，工作目录设为源码根目录，解释器指向安装依赖的虚拟环境。实际启动、取消和输出读取依宿主进程 API 实现；该片段仅展示参数形态。

## 结果处理

CLI 可能因前置条件不满足、风险阻断或内部错误返回非零状态。标准错误中的 `media-missher-diagnostic` 提供平台、类别与原因；不同路径还可能输出进度。不要把 stdout 当作始终只有一个 JSON 对象。

以输出记录和运行清单为依据。进程正常退出后也要检查 complete / partial / failed 等状态及字段完整性。超时或取消后，先确认本次子进程退出，再安排下一次任务。

- 昵称、模型猜测和示例占位符不能替代已确认目标。

- 不把 Cookie、调试 WebSocket 地址、完整账号清单或原始日志放入全局提示词。
- 不因失败自动扩大条数、切换账号、清除风险状态或改用另一条浏览器控制路径。

## 宿主差异

Codex、Hermes、DSH 等需要各自配置进程权限、工作目录和解释器。连接、工具注册、首次调用、平台采集应分别验证。本仓不包含 DSH `dsh.bundle`、npm 安装器或 MCP server；Git URL 不能直接当作这些插件入口。

模型和推理级别由宿主管理。集成时复用本运行时，不复制第二套解析、风险或导出逻辑。
