# 15.5.0 / Bundle 0.5.0：共享保护、版本预检、阶段进度

用户已在四平台各 1 条的真实实测及三项评估后授权「你看着升级一下版本」。本次为本地私有候选，不包含正式安装、推送、公开或扩大真实采集预算。

## 目标与取舍

同一 macOS 用户的入口必须共享采集互斥和 XHS 冷却/风险暂停，不能通过浏览器重启、端口或 runtime home 改变而获得新额度。采用用户级保守范围，而不是依赖会重启变化的 CDP session 标识；不同独立浏览器也串行，是明确的可用性取舍。保留每个安装的生命周期锁与旧采集锁。旧客户端不理解新锁，因此不能声称它们获得自动并发保护。

## 功能、数据与接口

- 新增 Python 用户级协调模块，固定 `~/.local/share/media-missher-shared` 私有目录；运行目录或 CDP 参数不能指定另一个共享目录。测试通过隔离 HOME 使用临时目录。
- 新核心直接运行和适配器运行都取得共享锁。适配器到核心仅传递受验证的继承文件描述符，不提供可由环境布尔值绕过的开关；验证 inode/owner/mode/lock。
- 从当前、默认和已经登记的旧 runtime home 保守迁移状态；最大启动时间和未确认风险保留。在共享锁下登记已知目录；共享 XHS 锁与旧目录状态锁覆盖整个批次，合并后同步写回各份状态。确认同步写回已知旧状态，避免相同旧暂停反复重放；中途失败会保守保留暂停，新旧状态损坏均停止。状态目录/文件不可链接，权限 0700/0600。
- 只读状态和显式本地风险确认使用同一共享状态，确认不能清除冷却，也不会触发采集。
- 同一个严格 VERSION 读取函数服务预检和采集；旧版在任何 Python/浏览器探测前明确报告所需和可识别的当前版本。
- 阶段事件使用固定枚举、平台、计数和 monotonic 耗时。核心/控制器的最终 JSON 合约保留；进度不包含账号、目标、URL、正文、Cookie 或任意异常文本。Harness SDK 没有原生实时进度接口，不伪造宿主 API；提供可用的本地进度与结果阶段耗时，并清楚标注宿主展示边界。

## 验收

两个不同 home 竞争同一锁；直接核心与适配器互斥；子进程继承和取消后释放；换目录保留冷却/暂停；迁移幂等和故障保守；风险确认保留冷却；旧版本预检不访问 CDP；分片进度安全解析、失败/取消阶段耗时、最终输出兼容。保持名单前置、手动登录、默认不启浏览器、XHS 10 条/3 页/600 秒、不自动重试、第三方声明与私有数据边界。

离线测试、隔离正常安装/原生 Harness 加载及包字节验证分别记录；15.4.0 的四条真实数据不冒充新版本实测。历史 0.2/0.3/0.4 包与证据不可覆盖。
