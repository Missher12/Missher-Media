# Media@Missher 17.0.0 私有交付

日期：2026-09-27。按用户指定从原 15.6.0 开发基准直接进入 V17，将运行时、通用 CLI 和 DSH Bundle 统一为 17.0.0。

本版仅使用 Chrome CDP，移除 Computer Use 执行链；保留五平台采集、多目标顺序执行、恢复、私有历史、截图、风险保护和选择导出。支持字段见根 DATA_CAPABILITIES.md，安装步骤见 QUICKSTART.md，examples/ 为明确标注的合成数据。

## 交付

完整包、Agent Setup、CLI tgz、DSH Bundle、源码包和 SHA-256 均位于根 dist/v17.0.0。构建器只打包审定的源码、文档和程序，排除浏览器数据、凭据、实采结果和本机验证证据。源码包提供逐文件摘要，完整包保留组件摘要。

## 验证

完整回归共 1,635 项通过：Python 1,289 项、DSH 291 项、通用 CLI 55 项；类型检查与构建通过。新增交付包排除、摘要及可重复构建测试。原生隔离安装通过：通用 CLI 的安装和 Skill 写入；DSH 0.1.7-rc.2 的安装、加载、合成调用与卸载。真实 Chrome CDP 连接、截图校验、可见风险停止和断开保留浏览器通过，页面为本地合成数据。

本次同时补齐 DSH 用户 Applications 目录和 Electron ASAR 布局识别，使用宿主自带 pnpm，并在写入 profile 前校验虚拟 CLI 路径。准确记录见 [机器可读验证](v17.0.0.validation.json) 与完整包 VALIDATION.json。

真实平台采集、当前用户账号登录、所有 Agent 的真实会话发现不在本次通过声明内。DSH 0.6.1 历史兼容改动尚未自动整合，宿主结果单独列出。首次安装依赖仍需要包源连接。

## 升级边界

源码与新交付为 17.0.0；本机旧 15.6.0 安装和冻结候选包保持原样。安装器保留恢复信息，不应强制覆盖归属于另一安装入口的同名 Skill。本轮没有公开仓库、发布 npm 或改动历史标签。
