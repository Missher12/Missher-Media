## 预算与使用

同一用户下正常开始间隔：B 站/抖音 60 秒、微博 90 秒、X 120 秒、小红书 600 秒。小红书单批最多 10 条/3 页，其余平台最多 20 条/3 页；计划可以进一步收紧。固定模式执行一批，需要多批则明确选择 `best_effort` 与截止时间。这些是本地工程限制，真实可取得的数据仍由平台页面决定。

详情、评论、截图保留现有显式请求与导航授权。跨任务内容复用沿用精确计划恢复；本版新增的是同实体观测补全，没有引入跨账号全局内容缓存、长期响应队列或主列表/详情双标签重构。

人工查看/确认的入口为 `python -m media_missher_runtime.safety_control` 与 `--acknowledge-risk --platform <平台>`，应由已升级的运行时 Python 执行。它不访问浏览器、不启动采集、不清除正常冷却。小红书旧 `current/scripts/xhs_safety.py` 维护命令继续兼容。实际路径与 `PYTHONPATH` 设置见 QUICKSTART.md。不要删除共享状态文件处理暂停。
