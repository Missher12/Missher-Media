# Media@Missher

> Missher 专用私有仓库。

Media@Missher is an independently maintained collection runtime and Codex skill for authorized Bilibili, Xiaohongshu, Douyin, and Weibo workflows. The current release is V15.2 (`15.2.0`).

## Versions

- `v15.2.0`: Xiaohongshu CDP-only ownership, request-bound comments, stricter detail evidence validation, safer screenshot fallback, and duplicate-page pagination hardening
- `v15.0.0`: CDP detail capture, optional Bilibili BrowserSkill assistance, and private screenshot release
- `v12.0.0`: first standalone shared-runtime release
- Git history before `v12.0.0`: independently authored skill and clean-runtime development history

See [the historical archive index](docs/history/README.md) for older local package evidence and the privacy/licensing reasons some raw bundles are intentionally not copied into Git.

## Private-use boundary

This repository is for Missher's private use and backup. It does not contain collected platform data, screenshots, browser traces, cookies, profiles, credentials, private target configuration, runtime state, virtual environments, or unlicensed third-party source bundles.

No repository-wide public-distribution license has been selected. Keep the repository private and do not publish release bundles until provenance and licensing review is complete.
